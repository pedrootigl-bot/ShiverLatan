# Shiver

Projeto da landing da **corretora Shiver**: divulgação da ferramenta que auxilia o trader na hora de compra e venda. A ferramenta não opera sozinha.

```
landing-page/    app Next.js (código e README de desenvolvimento)
backend/         autenticação Shiver via Playwright (login, cadastro, recuperação)
documents/       tese, slider, otimização e análises
```

Para instalar, rodar e entender o site, use o [README da landing](landing-page/README.md).

Para o backend de autenticação, veja [backend/README.md](backend/README.md).
